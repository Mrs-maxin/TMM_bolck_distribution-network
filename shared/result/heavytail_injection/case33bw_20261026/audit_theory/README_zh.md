# 直接给定重尾注入测试：理论与实现一致性复核

状态：分组t参数一致性检查不通过。本批次的分组t结果暂停用于检验新理论场景下的方法优劣。数值结果保留，未修改注入、MC交流潮流、电压分布参数或原项目内容。

## 1 核查依据和范围

核查依据为当前method_zh.md第3.2、4.2和4.4节，及上一轮独立副本中实际使用的计算入口、保存的电压分布模型和参数估计场景。对4种分布、4种分量数的52个分量逐个检查，读取已保存的模型，不重新生成注入、不求新潮流、不重新估计参数。

主流程实际采用：完整电源注入分布与固定原始负荷 → MATLAB快速计算电压 → AQGMM期望最大化 → 同K分量归属上的标准TMM和分组t按矩定参 → 电压二次型与条件特征函数 → 电气量CDF → 与独立MC交流潮流逐对象比较。

负荷与注入设置符合本次要求。标准TMM和分组t均未独立进行最大似然估计，这与当前文稿“在同K的AQGMM分量归属上按矩确定参数”一致。问题在于参数求出后，实际分布没有保持文稿声称的若干矩关系。

## 2 已确认的分组t问题

### 无界输入沿用了有限强度设置

Pareto等输入没有给定物理出力上限，代码却用12288个参数估计及参数选择场景中的最大偏差确定强度上限。method_zh.md式(16)和第4.4节要求该上限来自物理出力限值。有限场景中的最大出力不能等同于无界分布的物理上限。

### 参数计算用的强度矩积分不准确

TruncatedStrength用2000个均匀分位中点计算强度均值和矩，在本次较大的强度上限下误差明显。对保存的截断逆伽马分布作独立的对数变量自适应积分，Pareto、K=2、第1分量、第1组的强度均值为1.014932，而应为1；强度二阶矩目标17.237313，实际为24.403573，偏高41.6%。这与此前验证电气量CDF的积分不是同一个环节。

### 正定化和均值移动后的矩关系未重新验收

shift_grouped_t_case33.py先按目标协方差求散布矩阵，随后为使矩阵正定而缩小组间元素；必要时再缩小均值移动量。这些操作改变协方差或三阶矩，程序却没有重新检查理论要求是否仍然满足。

Pareto、K=2的两个分量，在参数估计使用的归一化电压坐标中，协方差整体相对差分别为18.8%和15.8%；换回原电压实部、虚部坐标后分别为14.4%和5.9%。这不是仅由坐标归一化产生的表面差异。它会改变节点电压变化幅度及支路两端电压之间的共同变化关系，继而影响支路功率分布。

此外，加入均值移动后，电压四阶矩还与强度的三、四阶矩有关。当前程序仍先用对称t情形的关系确定自由度，再计算均值移动量，没有联立保持电压四阶矩。Pareto、K=2、第1分量、第1组，归一化径向四阶统计量的目标为17.237313，最终构造的电压分布约为81.163201，即目标的4.71倍。该统计量是分组电压的四阶统计量，不是某个节点的普通峰度。

### 共同放大规则未覆盖全部重尾注入

旧规则要求至少两个注入共同放大才成组。Pareto情形P18未进入注入分组；补充电压方向后，被当作高斯处理的剩余电压方向最大超额峰度仍约1880。不能把这种结果视为“剩余方向近似高斯”条件已经成立。P18未成组并不表示其全部电压影响都被删除，但现有处理未充分解释其重尾影响。

### 固定负荷后的电压维数处理尚未完成适用性检查

本次入口将64个电压坐标保留为21个方向，独立场景的电压重构精度已检查，但这一处理对分组、自由度和尾部参数的影响没有单独验收。它是新增数值适配，不能仅因电压重构误差小就认定后续参数估计不受影响。固定负荷本身合理，不应为照顾程序重新增加负荷波动。

## 3 标准TMM必须单独评价

52个分量的标准TMM均值和协方差与式(9)的目标一致，协方差相对差最大约3.6e-16。K=2情形的四阶统计量也与对应公式一致。

但52个分量中有2个触及自由度4.1的下限，分别为Pareto和混用情形的K=1。Pareto、K=1的四阶统计量目标为47.597281，按下限构造的实际值为21。因此不能笼统宣称标准TMM的四阶矩在全部设置下都保持一致。这一下限沿用当前文稿，属于新场景中需要明确的参数可行性限制。

标准TMM部分未触下限的结果，仍不能自动解释为理论被反驳。当前文稿给出了给定电压分布后计算电气量分布的解析关系，以及特定条件下的分组依据；未给出对任意非t型重尾注入、任意有限K，尾部概率误差均小于GMM的普适保证。输入为重尾不等于交流潮流后的电压联合分布恰好属于所选t混合形式。

## 4 前一轮检查实际说明了什么

交流潮流与快速映射的物理精度检查有效；在已经构造出的电压分布下，电气量二次型和CDF反演检查也有效。但它们没有验证“构造出的电压分布是否满足预定的矩关系”。分布参数存在偏差时，正确的CDF计算仍会准确计算一个偏离目标的分布。

此前用固定无功保持不足解释支路无功误差，只描述了一个已观察到的物理偏差，尚不足以确定其主因。本次发现的上游参数问题也可能造成这项偏差，不能省略上游检查。

## 5 当前处理结论

本批输入、MC结果和全部不利结果保留。分组t比较暂不用于理论有效性判断；标准TMM按参数是否触及限制分别记录。后续应保持输入和MC不变，先明确无界重尾场景采用的分布模型与有限矩条件，再逐项验收均值、协方差、三阶及四阶统计量和电气量计算，完成后再比较尾部精度。

不能将当前含均值移动的模型直接删除截断后视为已完成适配。均值移动与强度成正比时，电压四阶矩涉及强度四阶矩，需重新检查自由度条件及参数可行性。
