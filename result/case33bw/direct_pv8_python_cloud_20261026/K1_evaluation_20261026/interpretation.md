# 当前K=1结果的描述性判断

用户已确认误差口径并授权恢复本次K=1比较。本次只读取已保存291组解析分布和独立3504组交流潮流，不重做源荷、交流潮流、参数估计，不扩算K=2、4。先前暂停状态已被本次指示更新，旧输出和1983e8b保留。

右尾CDF-RMSE和极端分位的改善方向不必一致。V18上AQGMM/标准TMM/本文分组TMM的右尾RMSE为7.37628/7.17226/7.08683个百分点，但q99绝对误差为0.0318673/0.0330498/0.0363106 p.u.。V33和网损也出现右尾RMSE变小、q99绝对误差增大的情况。支路P1、P16上分组TMM的右尾RMSE比AQGMM略小，但q99误差略大；P32的两个右尾指标则都略小。标准TMM在P1、P16、P32上右尾RMSE及q99误差均小于AQGMM，但这些支路的左端q01误差均增大。结果不能概括为某方法两侧尾部一致改善。

支路无功保留不利结果。Q17（17→18）的右尾RMSE为47.01744/47.47688/48.02920个百分点，本文分组TMM较差，虽然其q99绝对误差略小。Q13（13→14）右尾RMSE为12.18926/11.98446/11.31218个百分点，分组TMM较小。Q32（32→33）右尾RMSE为34.89408/35.14591/35.59476个百分点，分组TMM较大。P22（3→23）的AQGMM/分组TMM右尾RMSE为0.255073/0.255071个百分点，数值接近，不据该微小差别作优势结论。Q22的两者也接近；同对象标准TMM右尾RMSE为0.104361个百分点，小于AQGMM的0.143489个百分点。

均值接近不保证方差准确。V18的AC均值1.04326517 p.u.，三模型约1.046517 p.u.，方差均偏低约25%；V33方差也偏低约25%。P1的AC均值0.49215826 MW，三模型约0.418817 MW，方差偏低约26%。Q17的AC均值0.03225623 MVAr，三模型约0.0322643 MVAr，但方差约为AC的202/209/223倍；这个不利结果原样保留，其原因尚未定位。网损的三种模型均值与AC相差约0.000104 MW，但方差相对误差为+59.42%/+61.04%/+73.28%。不以均值误差替代方差或尾部评价。

全部97对象×3模型的左右尾RMSE、q01/q99、q005/q995及探索性q001/q999、全局矩和有符号/绝对误差均保存。CDF-RMSE分别使用左右各81个AC经验分位点及其实际右连续经验CDF，既不是平均绝对误差，也没有除以右尾CDF。模型分位由自身CDF反求。q001/q999不作主要优劣依据。

数值检查：模型CDF反求残差最大约7.5e-14；CDF网格插值最大已观察敏感性9.55e-5概率，即0.00955个百分点。浮点非单调修正最大6.44e-15，原始曲线不改动。电压幅值均值采用同一条件特征函数的Laplace积分，幅值方差为解析E[V²]减幅值均值平方；其自适应积分误差估计最高约1.75e-12 p.u.，容差加密差最高约3.6e-14 p.u.，不是连续强度积分的严格总误差界。P/Q与网损复用已保存强度求积权重的解析二次型矩。幅值积分也与原PDF积分核对，敏感性原样记录。

上述结论仅适用于当前K=1和固定日期划分，是逐对象描述性判断，没有全网平均排名；不包含有限交流潮流记录的不确定性检验。来源和误差定义见同目录comparison_readable.md、summary.json及逐对象CSV，完整定义见01_IDEA/plans/direct_pv8_K1_evaluation_20261026.md。
