# 8站直接光伏出力数据（2026-10-26）

用户要求直接选取一组现有出力数据，不增加出力波动，不采用预测加误差。

- 来源：`data/nrel_sind/co/Actual_*_5_Min.csv`，NREL气象驱动模拟出力，2006年。数据来源说明为 https://www.nlr.gov/grid/solar-power-data 。
- 选择范围：纬度39.55—39.95，经度−105.15—−104.75，共15站。
- 选择依据：当地时间10:00至14:00（不含14:00），计算各站出力除以其装机容量后、同一天内相邻5分钟变化绝对值的95%分位，取最大的8站；并列时按变化均方根排序。只比较原始出力，不运行电压分布参数估计或潮流。
- 保留全年同步出力记录，不挑选日期、不增添扰动、不估计新的光伏输入分布。原始MW表保留全年时刻；便于直接使用的标幺表只保留固定日间时间窗，全年日期均保留。
- 原始MW值保持源文件的文字数值；标幺值仅除以源文件名中的装机容量。各列仍保留同一时刻的站间关系。
- 输出：`data/nrel_sind/pv8_direct_2006/`，含全年MW表、日间标幺表、站点表和来源清单。入口：`tests/python/select_nrel_direct_pv8.py`。
- 日间变化指标用于选站，不代表静态电气量尾部，也不能证明TMM优于GMM。节点配置、算例装机容量、负荷、电气量限值及方法比较尚未开展。

状态：选择依据已登记；数据检查以输出目录的`selection_manifest.json`为准。
